# نظام المقاولات ERP - المرحلة 1 (النواة المحاسبية)

نظام سحابي بواجهة عربية (RTL) يعمل على الويب. هذه هي المرحلة الأولى: **المستخدمون والصلاحيات + دليل الحسابات + العملاء + الموردون + المشاريع + مراكز التكلفة + القيود اليومية (قيد مزدوج) + ميزان المراجعة + الأستاذ العام + سجل العمليات**.
الدليل المحاسبي هو نفسه دليل نظام الإكسل (119 حساباً).

## قواعد النزاهة المحاسبية المطبقة (على مستوى الخادم)
- لا يُرحَّل قيد غير متوازن، ولا أقل من سطرين، ولا سطر مدين ودائن معاً أو بلا مبلغ.
- الحسابات الرئيسية (المستوى 1 و2) والحسابات الموقوفة لا تقبل حركة.
- الحساب الذي يتطلب مشروعاً/مركز تكلفة يجب تحديده؛ ومركز تكلفة المشروع يُملأ تلقائياً.
- التاريخ يجب أن يكون داخل السنة المالية.
- القيد المرحّل **لا يُعدَّل ولا يُحذف**: يُعكس بقيد جديد (ويُمنع عكسه مرتين).
- كل عملية مهمة تُسجَّل في «سجل العمليات». ثلاث صلاحيات: مدير، محاسب، مطالعة فقط.
- عزل كامل بين الشركات (الجداول فيها company_id) تمهيداً لتعدد الشركات.
- حماية CSRF، وتجزئة كلمات المرور (PBKDF2)، وقفل مؤقت بعد 5 محاولات دخول خاطئة.

## تشغيل محلي (على جهازك)
```
pip install -r requirements.txt
LOAD_DEMO=1 ADMIN_PASSWORD=admin12345 uvicorn app.main:app --reload
```
افتح http://localhost:8000 وادخل بـ `admin / admin12345`. (يستخدم SQLite تلقائياً.)

## الاختبارات
```
pip install -r requirements-dev.txt
pytest                      # على SQLite
TEST_DATABASE_URL=postgresql://user:pass@localhost/dbname pytest   # على PostgreSQL
```

## النشر المجاني: GitHub + Neon (قاعدة البيانات) + Render (التطبيق)
1. **GitHub:** أنشئ حساباً ثم مستودعاً خاصاً (Private) وارفع محتويات هذا المجلد.
2. **Neon (قاعدة البيانات):** سجّل في neon.com ← New Project ← انسخ **Connection string** (يبدأ بـ `postgresql://`). الباقة المجانية دائمة، وتنام القاعدة عند الخمول وتصحى تلقائياً.
3. **Render (التطبيق):** سجّل في render.com ← New ← Blueprint ← اختر المستودع (يقرأ `render.yaml`). عند الطلب:
   - `DATABASE_URL` = رابط Neon.
   - `ADMIN_PASSWORD` = كلمة مرور قوية للمدير.
   - غيّر `COMPANY_NAME` لاسم شركتك.
4. بعد اكتمال النشر افتح رابط Render (https://....onrender.com) وادخل بـ `admin` وكلمة المرور التي وضعتها.
5. ادخل «إعدادات الشركة» وحدد بداية السنة المالية، ثم أضف المستخدمين.

**ملاحظات الباقة المجانية:** خدمة Render المجانية تنام بعد 15 دقيقة بلا استخدام وأول طلب بعدها يستغرق 30-60 ثانية. لا تستخدم قاعدة Render المجانية (تُحذف بعد مدة)؛ ابقَ على Neon. هذه الشروط تتغير من حين لآخر فراجع صفحات الأسعار قبل الاعتماد عليها. للتشغيل الفعلي بعد شراء استضافة: غيّر `plan` في `render.yaml` أو انقل المشروع لأي خادم (يعمل بأمر `uvicorn` واحد) وأبقِ نفس `DATABASE_URL`.

## النسخ الاحتياطي
- من Neon: Branching / Point-in-time restore (حسب الباقة)، أو `pg_dump "$DATABASE_URL" > backup.sql` أسبوعياً على الأقل.
- لا تعتمد على الباقة المجانية وحدها لبيانات مالية: احتفظ بنسخة تصدير دورية.

## الأمان (قبل إدخال بيانات حقيقية)
- ضع `SECRET_KEY` عشوائياً طويلاً (Render يولّده) و`SESSION_HTTPS_ONLY=1` (مضبوط في render.yaml).
- لا تترك `LOAD_DEMO=1` في الإنتاج. غيّر كلمة المرور الأولى. راجع «سجل العمليات» دورياً.
- الإنشاء التلقائي للجداول مناسب للمرحلة 1؛ قبل إضافة تغييرات مستقبلية على الجداول نضيف Alembic للترحيلات.
